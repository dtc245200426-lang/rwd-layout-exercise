# Bài tập tạo layout với RWD

Mở `index.html` bằng trình duyệt, giữ `styles.css` cùng thư mục. Layout sử dụng DIV và CSS, không cần thư viện.

- Desktop: thanh điều hướng, ba cột Link / nội dung / ADS và footer theo hình mẫu.
- Tablet (991px trở xuống): hai cột, quảng cáo chuyển xuống hàng dưới.
- Điện thoại (600px trở xuống): các vùng xếp dọc, thanh điều hướng tự xuống dòng.

Các liên kết là liên kết minh họa. Dùng viewport meta, CSS Grid, Flexbox và media queries để điều chỉnh bố cục.
